Micro Progress Indicator

Technical Architecture

Value-Type State Engine

Built with TimerEngine, a pure value-type state machine conforming to Codable. Ensures predictable states and easy serialization for crash recovery.

User Sandbox Directory

Utilizes JSON file persistence for session logs and configuration. Preserves memory footprint and is lightweight on disk.

Swift 6 Concurrency

Fully compliant with strict concurrency checks. Guarantees race-free data flow across asynchronous timer ticks.

Accessory Application

Operates as a macOS accessory agent (dock icon hidden, activation policy set dynamically), keeping your workspace clean.
